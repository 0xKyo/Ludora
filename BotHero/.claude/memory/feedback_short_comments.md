metadata:
  type: feedback
---

Keep comments to a maximum of 2 lines. If an explanation needs more than that, cut it down to the essential "why" instead of spelling out full context/rationale in the comment body.

**Why:** User explicitly corrected this after reviewing comments that ran 3-4 lines.

**How to apply:** Applies to comments in any codebase being worked on unless told otherwise. When writing a "why" comment, aim for one line; only use a second line if truly necessary. Never write 3+ line comment blocks — trim to the core reason instead of full narrative.
